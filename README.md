# 📚 Bookstore Sales Analysis Dashboard (Power BI)

This project analyzes a fictional bookstore's performance using Power BI. It covers sales, inventory, customer behavior, and rating trends — delivering insights that can drive marketing, inventory decisions, and customer engagement.

## 📊 Dashboard Highlights

### 1. Executive Overview
- Total Revenue
- Total Books Sold
- Top Customers & Books by Revenue
- Genre Sales Performance

### 2. Sales Performance
- Top Selling Books
- Books with No Sales
- Sales Trends Over Time

### 3. Customer Engagement
- Genre Diversity by Customer
- Most Active Raters
- Top Customers by Spending

## 🛠 Tech Stack
- Power BI
- SQL (MySQL)
- Excel / CSV
- DAX for measures and KPIs

## 📁 Files Included
- `PowerBI_Dashboard.pbix` - Main report file
- `bookstore_dataset.sql` - sample data
- `dashboard_screenshot.png` - Final dashboard snapshot

## ✅ Key Takeaways
- Identified top-performing genres and customers
- Discovered books needing discounting or promotion
- Measured sentiment and rating patterns
- Used DAX to calculate average ratings, genre counts, and more
